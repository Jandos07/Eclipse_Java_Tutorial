# Java Swing · Scholarship Application Form

A desktop form exercise built with Java Swing, including student-information fields, a CAPTCHA prompt, and a submit button.

**Focus:** Java · Swing · Eclipse  
**Status:** Coursework prototype

## Repository guide

| Path | Purpose |
| --- | --- |
| [TEST/src/ScholarshipApplicationForm.java](TEST/src/ScholarshipApplicationForm.java) | Form layout, widgets, and event handling |
| [TEST/.project](TEST/.project) | Eclipse project configuration |

## Getting started

Requires a JDK and a desktop environment. In Eclipse, import `TEST` as an existing project, then run `ScholarshipApplicationForm` as a Java application.

## Notes

The banner image uses an absolute path from the original development machine and is not included in this repository. Update that path or supply the asset when reproducing the interface.
